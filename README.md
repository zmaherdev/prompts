A colletion of prompts I use for local or cloud AI

# Components
1. [ponycloud](cloud/ponycloud.md): A [ponytail](https://github.com/dietrichgebert/ponytail) generalization and adaptation for cloud AI (modified by Deepseek Web)
2. [ponycloud-mini](cloud/ponycloud-mini.md): same as ponycloud but adapted for ones refusing it like Gemini and ChatGPT (modified by Deepseek Web)
